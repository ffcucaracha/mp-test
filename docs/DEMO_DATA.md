# Stage 16 — Seed/demo data

Демо-данные собраны как несколько связанных историй, а не как набор случайных записей. Они нужны для стабильной демонстрации MVP без ручного заполнения перед питчем.

## Важно: seed выполняется только на пустой базе

Если локальный PostgreSQL уже содержит пользователей, новый seed не применится автоматически.

Для полностью чистого demo reset:

```bash
docker compose down -v
docker compose up -d --build
```

**Внимание:** `docker compose down -v` удаляет локальный volume PostgreSQL и все локально созданные данные.

## Поля и приватность

В seed есть все **52 поля** из `03-09-2026_fields.kml` общей площадью 2 750,9 га:

- сохранены реальные названия, культуры 2026 года, контуры, центры и рассчитанные площади;
- поля распределены между пользователями по шести компактным географическим кластерам;
- Variant A — открытые детали, Variant B — детали по запросу к владельцу всего хозяйства;
- площади отдельных полей — от 2,8 до 168,1 га;
- история культур за 2–3 сезона.

Первые семь ID зарезервированы за связанными демо-сценариями. Остальные поля также загружаются из KML и получают детерминированные ID и вариант приватности.

При обновлении исходного KML набор можно пересобрать:

```bash
cd backend
PYTHONPATH=. python scripts/generate_seed_fields.py /path/to/03-09-2026_fields.kml
```

## Публикации

Seed покрывает обязательные статусы:

```text
sowing      — посев
sprouts     — всходы
flowering   — цветение
problem     — проблема
harvest     — урожай
treatment   — обработка
```

Есть как положительные реакции `🌾 +1`, так и отрицательные `🥀 -1`, а также содержательные комментарии.

## Privacy A/B

Доступ запрашивается один раз ко всем полям добавленного соседа. В seed подготовлены оба состояния:

- `pending`: Илья → все поля Анны;
- `approved`: Анна → все поля Ильи.

Это позволяет показывать эксперимент без ручной подготовки двух отдельных баз.

## Alerts

### Pesticide

Илья планирует обработку поля `№ 18`. Пасека Ольги расположена между этим полем и её полем `№ 19`, поэтому Ольга уже имеет непрочитанное pesticide alert.

### Weather

Анна имеет непрочитанное weather alert для поля `№34.2` с риском температуры ниже 0 °C.

## Рекомендуемый 2–3 минутный demo flow

1. Войти как **Анна Морозова**.
2. Показать локальную ленту и разные статусы публикаций.
3. Открыть «Поля» → `№34.2` → историю культур.
4. Показать поле `№ 34.1` с Variant B и privacy-механику.
5. Показать weather alert.
6. Переключиться на **Ольгу Лебедеву**.
7. Открыть предупреждения и показать pesticide alert от Ильи.
8. Показать пасеку и радиус предупреждений.
9. При необходимости вернуться в ленту и показать ML-анализ проблемы / human-in-the-loop.
10. Завершить monetization experiment: teaser → тестовая реклама → предложение Plus без рекламы.

## Что seed сознательно не делает

- не создаёт fake ML feedback: его лучше выполнить живьём на демонстрации;
- не создаёт monetization events заранее, чтобы конверсионные события отражали реальные действия тестировщиков;
- не подменяет real weather API — weather alert нужен как устойчивый demo fallback;
- не содержит lorem ipsum и бессмысленных пользователей.
