# API AgroConnect

После запуска backend интерактивная спецификация доступна по адресам:

- Swagger UI: `http://localhost:8000/docs`;
- ReDoc: `http://localhost:8000/redoc`;
- исходная OpenAPI-схема: `http://localhost:8000/openapi.json`.

Для демонстрации жюри доступна отдельная серверная страница `http://localhost:8000/internal/dashboard`.
Она не является частью мобильного клиента и строит диаграммы по текущим данным БД: событиям,
отзывам, заявкам доступа, предупреждениям и ML-анализам.

Swagger позволяет раскрыть любой endpoint, посмотреть схемы запросов и ответов, подставить
параметры и выполнить запрос к локальному MVP.

## Особенность MVP: идентификатор пользователя

В демо нет настоящей авторизации. Текущий пользователь передаётся как `user_id`:

- в query-параметре для чтения и простых действий;
- в JSON-теле для создания и изменения сущностей.

Это сознательное упрощение хакатонной версии. В production `user_id` не должен приниматься
от клиента: его следует получать из access token.

## Основные сценарии

| Сценарий | Endpoint |
|---|---|
| Проверить backend | `GET /api/health` |
| Получить тестовых пользователей | `GET /api/users` |
| Получить поля хозяйства | `GET /api/users/{user_id}/fields` |
| Задать один режим для всех полей | `PUT /api/users/{owner_id}/field-access-mode` |
| Найти хозяйства рядом | `GET /api/nearby-farmers?user_id={id}&radius_km=100` |
| Добавить соседа | `POST /api/neighbors/{neighbor_user_id}?user_id={id}` |
| Посмотреть поля соседа | `GET /api/neighbors/{neighbor_user_id}/fields?user_id={id}` |
| Запросить все поля соседа | `POST /api/neighbors/{owner_id}/access-requests` |
| Ответить на заявку | `PUT /api/access-requests/{request_id}` |
| Открыть ленту | `GET /api/feed?viewer_id={id}` |

## Доступ к полям хозяйства

У одного хозяйства действует ровно один режим:

- `A` — все поля открыты;
- `B` — точные данные всех полей закрыты, пока владелец не одобрит заявку конкретного соседа.

Заявка создаётся не для отдельного поля, а для пары «владелец хозяйства — сосед». После
одобрения сосед получает доступ ко всем текущим и будущим полям этого хозяйства.

Лента объединяет публикации из географического радиуса пользователя и публикации добавленных
соседей, даже если они находятся дальше выбранного радиуса.

## Ошибки

Ошибки FastAPI имеют формат:

```json
{
  "detail": "Human-readable explanation"
}
```

Наиболее частые статусы: `404` — сущность или связь «сосед» не найдена, `403` — действие
доступно только владельцу, `409` — сначала нужно добавить фермера в соседи, `422` — неверные
данные запроса.
